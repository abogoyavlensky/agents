# Judgment calls

- **Verified released vs unreleased state.** Latest tag is `v0.1.2`; three commits sit on master after it (Discord link, aero example, transitive-deps PR #40). Everything in the post is therefore unreleased, and the closing line says so explicitly.
- **Corrected the "mvn deps" framing.** PR #40's title says "Support mvn deps directly and transitively", but the actual shipped behavior (per the master README) is transitive discovery from `deps.edn`/`project.clj` with well-known Maven coordinates resolved through a curated git-mapping registry. Direct `:mvn/version` coords are still rejected by design (let-go runs libraries from source). The post describes what the code does, not what the commit title says.
- **Hedged the Go-deps timeline.** The `:go/*` work lives on the `go-deps` branch and, per its own plan doc, depends on let-go's `integration/go-interop` branch. let-go's latest release is v1.12.2 and the interop work is not in it, so the post says this needs a let-go release first rather than promising a date.
- **Ready answer for the likely awkward question** ("why not just support `:mvn/version`?"), kept out of the post per the skill: "let-go runs libraries from source, so coords are git or local; instead of downloading jars, lgx pins known Maven coordinates to their verified git tags automatically, and tells you the exact coord to add for anything it can't pin."
- **Left out:** the landing-page branch (stalled since June, not user-facing news), the June wazero/sqlite-driver experiments (superseded by the Go-deps direction), and the with-aero example (minor, and I could not quickly verify it runs against released let-go 1.12.x, since several aero gotcha fixes lived on let-go branches).
- **Tone and format:** audience is the existing lgx Discord channel, so no re-pitch of lgx itself; one structural emoji per bullet; hyphens instead of em-dashes; unpinned status-update shape (bullets of in-flight work plus a released/unreleased line).
- **Version numbers quoted** (`v1.57.0` for modernc.org/sqlite, `v0.1.2` for lgx) come from the go-deps branch README and git tags respectively; the sqlite version is an example from docs, not a tested pin.
- **No Discord paste gotcha:** the post uses inline code only, no nested triple-backtick fences, so it can be wrapped in an outer fence safely.
