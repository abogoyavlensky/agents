# gizmo

A tiny CLI that does the thing across all your repos.

## Installation

```bash
brew install acme/tap/gizmo
```

Or grab a prebuilt binary for your platform from the
[latest release](https://github.com/acme/gizmo/releases/latest).

## Development

```bash
lgx run -- run
lgx test
lgx fmt
lgx lint
```

Build a binary:

```bash
lgx build
bin/gizmo --version
```
