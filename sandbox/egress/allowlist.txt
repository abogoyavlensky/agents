# Hostname allowlist for agent-proxy (/etc/agent-proxy/allowlist.txt).
#
# Format:
#   - one hostname per line; `#` starts a comment
#   - an entry matches itself and all of its subdomains
#     (github.com allows api.github.com, but not notgithub.com)
#   - a line containing only `*` allows every hostname: discovery mode
#   - a missing, empty or unreadable file denies everything
#   - edits are picked up automatically when the file's mtime changes
#
# Only HTTPS on port 443 and plain HTTP on port 80 pass, whatever is listed
# here. IP literals, localhost and *.local / *.internal names are always denied.
